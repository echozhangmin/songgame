01 · DAILY LOOP

每天四个行动点，夜里结算，三十天走完一科
01
日始 · 入幕
按日切场景；赶路日先扣 2 点行动。
第 8 日山匪、第 11 日水匪、第 12 日虹桥、第 15 日门税为固定遭遇。
02
事件判定
第 3 日起 50% 触发一次小事件，按场景过滤，一局只出现一次；「贵人」权重减半。
03
行动 ×4
温书、歇息、宴饮、拜访、打听、题诗、抄书……各耗 1 点；答对才加智力，答错也挡住夜里衰减。
04
入夜结算
未维护的属性 −1；精力 ≤ 2 时 45% 再 −1；扣食宿。考试日与放榜段不结算衰减。
05
次日 / 终局
属性归零即终：胸无点墨、病卧逆旅、孤身无援、困于逆旅。否则进入下一日。

回到 01，直到第 25 日进贡院

放榜 · 第 28 / 30 日查榜 → 琼林宴 → 状元／一甲／二甲／同进士／特奏名

03 · BUILD PIPELINE

数据与画面分离，一个 Python 脚本产出两种发布物

源

  • game.template.html — 规则、文案、CSS
  • data/quiz_150.json — 题库（含 afterCutoff）
  • data/glossary.json — 词条（据／推断／设）
  • assets/*.jpg — 场景与画轴
→

构建

  • python3 build.py
  • 题库／词条注入占位符
  • 图片 base64 内嵌
  • 生成 词条表.md
  • --dist：转 WebP、外链
→

产物

  • 北宋赶考记.html — 单文件，双击即玩
  • index.html — GitHub Pages 入口（同内容）
  • dist/ — 拆分资源，上 Cloudflare Pages
  • 词条表.md — 可打印的史料清单

单文件是"离线可玩"的承诺；dist/ 是"手机 4G 也能开"的答案。两者同一份模板，不允许各自漂移。

05 · EVIDENCE

每个词条都要能回答：这是原文，还是转述，还是我编的

推断据书转述 · 49 条

只到书名／篇名一级，用「所述」标明，不假装是原文。
