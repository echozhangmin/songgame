# 北宋赶考记 · 嘉祐二年

仓库：https://github.com/echozhangmin/songgame

一个**单文件 HTML** 的北宋科举模拟游戏：临川举子正月初十启程，三十日后在汴京应省试、殿试。
双击 `北宋赶考记.html` 即可在浏览器里玩，不联网、不装依赖。
启动先进**开始页**：可「继续上次」（显示上次行至第几日、在哪一幕、三项属性）或「重新开始」；进度每一步自动存 localStorage。

> **为什么是嘉祐二年（1057）**：这一榜是欧阳修主考、梅尧臣点检试卷，苏轼、苏辙、曾巩、曾布、程颢、张载、吕惠卿同年登第，号称科举史上最豪华的一榜。把主角放在这一年，你才能在汴京的酒楼里真的遇见这些人。
> 十二幕：家塾、长亭、驿站、山道、汴河（上）、**虹桥闸口**、汴河（下）、城门、酒楼、书库、号舍、放榜。

## 一、玩法

每日 **4 点行动**，温书、歇息、交游各占 1 点。

| 行动 | 消耗 | 效果 | 维护 |
|---|---|---|---|
| 温书做题 | 1 点，精力 -1 | 智力 +1，抽一题作答并给解析 | 智力 |
| 歇息 | 1 点 | 精力 +3（驿站 +4，舟中 +2） | 精力 |
| 宴饮结交 | 1 点，盘缠 -2 | 人缘 +2；遇同榜举子则再 +1 智力 | 人缘 |
| 拜访大儒 | 1 点，盘缠 -1 | 智力 +1、人缘 +1（人缘 <3 见不到；人缘 ≥8 再 +1 智力） | 智力・人缘 |
| 打听消息 | 1 点，盘缠 -1 | 人缘 +1，探知今年主司偏好 | 人缘 |
| 题诗换宿（驿路） | 1 点，精力 -1 | 按题作诗，盘缠 +2～5 | 智力 |
| 街头鬻诗（市口） | 1 点，精力 -1 | 按题作诗，盘缠 +2～4 | 无 |
| 凭栏观景（舟中） | 1 点 | 精力 +1、人缘 +1 | 精力・人缘 |
| 抄书换钱（书库） | 1 点 | 盘缠 +3，智力 +1，精力 -1 | 智力 |

**入夜结算**：当天没做的那一类事，对应属性各减 1 分；任一项归零，旅程终止。属性 ≤2 时会提前警告。
**赶路日**（山道、汴河 10–11 日与 13–14 日）：赶路本身耗掉 2 点，只剩 2 点行动，必有一样要放下。

**第 12 日「虹桥 · 汴河闸口」**：船等潮，可上岸半日——桥头走走（人缘+1、精力+1）、上岸补给（盘缠-1、精力+2）、打听消息、题诗换宿。
到桥即遇**桥头**一场：听书（-1 贯、智力+1）／跟牙人看房（-3 贯、精力+2）／只在人堆里站着（人缘+1、精力-1）。
**行程日**（长亭、考试、放榜）：不结算衰减，只扣食宿。

**第 15 日「入京手续日」**（城门）：四天来第一次进京，要办三件事——
- **投状报名**：礼部交解状，1 贯，人缘 +1（领号舍凭据）
- **寻住处**：州桥客栈（-2 贯、精力 +2）／城外僧舍（-1 贯、精力 +1）／投同乡（人缘 ≥5，免费、人缘 +1）
- **踩点贡院**：智力 +1、人缘 +1，**省试第一场第一题会替你排除一个错项**

进门时还会撞上**门税**：守门吏要抽行李税，给 2 贯了事，或与他理论（精力 -1、人缘 -1）。

四条失败线：胸无点墨（智力 0）、病卧逆旅（精力 0）、孤身无援（人缘 0）、困于逆旅（盘缠为负）。

## 二、题诗

点「题诗换宿」或「街头鬻诗」，会弹出一张**命题诗笺**：由题主开口相邀，语气一律是鼓励的——"不拘工拙，只管写来"、"写出来，心里会松快些"。你当场写四句，交卷后评上、中、下三品。

**十八个题材**（你列的十三题，我补了五题）：

| 你列的 | 我补的 |
|---|---|
| 山川、赠友、故乡、父母、兄弟、勤学、场屋之忧、前程、报国、清贫、边事、生命、仕途 | 羁旅、民生、咏物、雅集、禅意 |

每道题都附一首同题名作作示范（山水用王维、思乡用李白、父母用孟郊《游子吟》、报国用王昌龄、民生用李绅、咏物用王安石的《梅花》）。

**判分只看一条**：字数是否对齐。

| 情况 | 品第 | 程仪 |
|---|---|---|
| 四句，每句字数一样（五言、七言最好） | **上品** | 驿壁 5 贯 / 街头 4 贯 |
| 其余（句数不对，或句子长短不齐） | **中品** | **分文不给** |

中品不给钱，但话仍是好话："肯写就好。下一回写四句、每句字数一样，便是上品——主人家也才好奉上程仪。"所以乱写一首等于白耗一点行动与一点精力，这比扣钱更让人长记性。

对仗不参与判分，只在评语里点一句——"中二联相对"是锦上添花，写不出来也不扣分。评语一律是鼓励的：上品说"四句齐整，字字相当，已是一首成样的诗"；中品说"肯写就好，下一回写四句、每句字数一样，便是上品了"。

**一地一首**：同一个场景只能题（鬻）一次诗，主人会说"此地壁上已有你的诗，换处再写罢"——免得反复刷钱。全程最多写四五首，写过的都进「诗囊」，结局页统计「此行得诗 N 首」。

> **对仗现在只作点缀**：另外做了一张约三百字的字类表（天象、地理、草木、方位、颜色、数目、动词、形容……），同位比对相邻两句，能认出"明月松间照／清泉石上流"这种工整的对，判出来会写进评语。误差在所难免，所以它不参与给分。

## 二点五、支线事件

每天开始时（第 3 日起）有 **50%** 概率触发一次小事件，按所在场景过滤，一局内每个事件只出现一次。

| 事件 | 出现地 | 结果 |
|---|---|---|
| 遇盗 | 山道 | **精力 -1，盘缠 -2**（你护住书箱，膝盖磕青） |
| 水贼 | 舟中 | 精力 -1，盘缠 -2 |
| 骤雨 | 山道、舟中 | 精力 -1 |
| 同乡 | 驿/镇/山/舟 | 人缘 +1，盘缠 +1 |
| 书肆 | 驿/镇/书库 | **二选一**：买程文（盘缠 -3、智力 +1）／只翻不买 |
| 山寺 | 山道 | **二选一**：听说法（精力 +1）／捐香火（盘缠 -2、人缘 +1） |
| 醉客 | 酒楼 | **二选一**：劝架（精力 -1、人缘 +1）／避到楼上 |
| 贵人 | 酒楼、驿站 | **二选一**：自报家门（人缘 +1、盘缠 +2）／谦称不足道（智力 +1） |

直接生效的事件弹窗只报结果；二选一的事件由你当场决定。事件也会写进行记，不影响当天的行动点。

### 山匪与水匪（固定遭遇）

- **第 8 日（山道）遇山匪**、**第 11 日（舟中）遇水匪**，各一次，必定发生。
- 三个选项：舍财（盘缠 -2）／硬拼（精力 -2 或 -1）／**先做准备才有的第三条路**。
- 山道的第三条要在前一日先花 1 点行动「结伴同行」；舟中的要在前一日「系舟守夜」。没做准备，该选项是灰的。

山道新增两个动作：**结伴同行**（盘缠 -1、人缘 +1，解锁山匪第三条路）、**夜宿山寺**（精力 +1、智力 +1）。
舟中新增两个动作：**系舟守夜**（精力 -1，解锁水匪第三条路）、**与船家闲谈**（人缘 +1、智力 +1）。

## 二点六、词条（释义与史料）

正文里带虚线的小词可以点开，看释义与出处；**动作按钮名字后面带「解」小字的**也能点（不会触发动作）；顶栏「词条」打开索引，共 **54 条**。完整清单（含释义、出处、备注）见 [词条表.md](词条表.md)。

每个词条分三部分：**释义**、**出处**、**备注**。出处分两档，避免把转述冒充原文：

- **原文**：确定原文的才加引号，例如
  - 行卷 —— 赵彦卫《云麓漫钞》卷八：“唐之举人，先藉当世显人，以姓名达之主司，然后以所业投献；逾数日又投，谓之温卷。”
  - 长亭 —— 李白《菩萨蛮》：“何处是归程，长亭更短亭。”
- **所述**：只到书名/篇名一级，用“所述”标出，例如“《宋史·选举志一》所述：礼部贡院掌受诸州解送举人名籍”。

备注会写明今古差异，比如：

- **程仪**：宋人多称“资装”“程费”，**“程仪”多见于明清小说**，本作取其易解。
- **号舍**：宋人多称“席舍”“试廊”，**“号舍”是后世通称**。
- **盘缠**：宋人实用铜钱、交子、金银，另有“驿券”可免费住驿；本作抽象为唯一货币。

## 三、人物（嘉祐二年，汴京）

酒楼、书库、舟中、驿站里会遇到真实的历史人物。每人只遇一次，附一句史料；**同一场景内的出场次序是固定的**，不会随机跳人。

| 场景 | 同游（人缘 +2，＋1 智力） | 长者（智力 +1、人缘 +1） |
|---|---|---|
| 临川 · 家塾 | — | 乡先生（提王介甫庆历二年登第事） |
| 官道 · 驿站 | 苏轼 → 苏辙 | — |
| 汴河 · 舟中 | 苏轼 | **苏洵**（携二子入京，自己屡试不第） |
| 御街 · 酒楼 | 苏轼 → 苏辙 → 曾巩 → 张载 → 吕惠卿 → 曾布 | **欧阳修 → 梅尧臣 → 司马光** |
| 国子监 · 书库 | 曾巩 → 张载 → 程颢 | 梅尧臣 |

**行卷的回音**：投过行卷的人，第 25 日天将明时会有人叩门，从门缝递进一纸短笺——智力 ≥7 得"文气已足，只宜敛锋。策问若及河渠，可据《禹贡》立论"，人缘 +1、智力 +1，行卷考运由 +0.02 提到 +0.04；智力不足 7 则只得到"笔下太急。入场先定章法，再落字"，人缘 +1。放榜那天，榜下会多一句"欧阳公在贡院提起过你的卷子"。

**想见欧阳修，用新加的「投行卷」**：酒楼里的一次性动作，花 2 贯，携旧作到礼部衙前投卷，欧阳修必见——回话是"文从字顺，可再简。少年人肯把话说尽，是长处，也是短处"，另得智力 +1、人缘 +1，并留下"行卷"的考运（省试加成 +0.02）。

不用投行卷的话，酒楼里连点三次「拜访大儒」也能依次见到欧阳修、梅尧臣、司马光；只点一两次，就可能只见到后两位——这就是你上次没见到他的原因。

- **欧阳修**（知贡举）："文从字顺，可再简。少年人肯把话说尽，是长处，也是短处。"
- **梅尧臣**（点检试卷官）："状难写之景，如在目前；含不尽之意，见于言外。"说着抬眼看你："足下这一联，景是够了，意还欠些。"
- **司马光**（谏官）："取士当先德行，而后文艺。"说完略一颔首："足下文章，仆读过。"
- **苏洵**（四十八岁）：携二子赴京，自己屡试不第，把文稿递给你："足下看看，可还有可取之处？"
- **苏轼**（二十一岁）：与弟苏辙同来应举，见你案头《庄子》，拊掌笑道："足下亦好此么？仆读《逍遥游》，只觉天地都宽了。"

黄庭坚 12 岁、米芾 6 岁，这一科他们还在家乡读书，所以没有让他们出场。

## 四、考试与结局

- **省试**：第一场诗赋（先秦・秦汉）、第二场经义（魏晋・隋唐）、第三场策论（五代北宋・隋唐），各 5 题，共 15 题。
- **殿试**：3 题。
- 省试答对 <8 题直接落第；≥8 题入殿试。
- 结局分数（0 到约 1.0）：

```
zhiCoef   = 0.60 + 智力/25          # 智力 5 → 0.80，智力 10 → 1.00
jingCoef  = 精力≥6 ? 1.0 : 精力≥3 ? 0.88 : 0.75
score     = ( 省试正确率 × 0.62 × zhiCoef
            + 殿试正确率 × 0.26
            + 人缘/10 × 0.12
            + 传闻加成 0.03 ) × jingCoef
```

| 分数 | 结局 |
|---|---|
| ≥0.88 | 状元 |
| ≥0.78 | 一甲进士 |
| ≥0.68 | 二甲进士 |
| ≥0.58 | 同进士出身 |
| 其余 | 特奏名 |

## 六、无头测试

用 macOS 自带的 JavaScriptCore（JXA）跑游戏逻辑，不需要浏览器：

```bash
osascript -l JavaScript sim.js                     # 180 局平衡测试
MODE=neglectYuan osascript -l JavaScript sim.js     # 验证「孤身无援」可触发
MODE=neglectJing osascript -l JavaScript sim.js     # 验证「病卧逆旅」可触发
```

55%／70%／85% 三档作答正确率各跑 60 局：正常经营不会崩盘，55% 水平多为同进士或特奏名，85% 水平多为一甲、约六分之一状元。

题诗判定另有单独用例：山水（王维）、思乡（李白）、送别（王维《渭城曲》）、怀古（刘禹锡）均判上品；跑题的山水诗投"送别"题会掉到中品；乱写判下品。

## 八、已知取舍（等你拍板）

1. **诗的好坏只由字数决定**：这是你定的标准——字数对齐即上品。所以"今天真高兴／我们去喝酒／明天再读书／一定考得好"也会拿上品。若要更严，最省事的做法是"字数对齐 + 至少一联相对"才算上品；对仗靠字类表近似判断，认不认识全看表里有没有那几个字。
2. **人物只出现一次**：每人遇过一次就不再出现，30 天里最多遇见 10 位。想让人物贯穿全程（例如苏轼考前考后各一场），可以改成按日解锁的多段对话。
3. **智力会顶满**：温书 +1／次、五点就到顶。想让智力全程吃紧，可把初始值降到 3。
4. **盘缠仍偏宽**：实测平均剩 12 贯。题诗奖励 +2～5 贯之后更宽了，可以考虑把京城房钱涨到 3 贯。
5. **场景插图空缺**：目前每个场景用一个巨型汉字（塾／亭／驿／道／舟／门／市／库／院／榜）做水印，等那 10 张水墨图做出来换成 `<img>` 背景。

## 九、发布

每次改完，一条命令发布到 GitHub（仓库：https://github.com/echozhangmin/songgame ）：

```bash
./deploy.sh "这次改了什么"
```

它做三件事：`build.py` 重新生成 → `git add -A` 并提交 → `git push`。

仓库里还装了 `.git/hooks/post-commit`：**任何一次提交都会自动推送**，所以就算你直接 `git commit`，也会同步到 GitHub。推送失败不会阻塞提交，日志在 `/tmp/git-autopush.log`。

### 在线游玩（GitHub Pages）

`build.py` 会同时生成 `index.html`（与 `北宋赶考记.html` 内容相同），专门给 Pages 当入口。

开启方式：仓库 **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**。
一两分钟后可访问 **https://echozhangmin.github.io/songgame/** ，手机浏览器也能玩（进度存在该浏览器的 localStorage 里，与本地文件不互通）。

> 注意：Pages 是公开站点，任何拿到链接的人都能玩；页面里不含任何私密数据。
